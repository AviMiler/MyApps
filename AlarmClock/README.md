# שעון מעורר (AlarmClock)

אפליקציית שעון מעורר מלאה לאנדרואיד (minSdk 26, targetSdk 34), בקוד Kotlin
ללא ספריות חיצוניות מעבר ל-AndroidX ו-Material.

## יכולות

- רשימת התראות עם מתג הפעלה/כיבוי לכל התראה.
- מסך עריכה: שעה, שם, ימי חזרה בשבוע (או חד־פעמי), משך צלצול, עוצמה,
  רטט ומשך נודניק.
- **משך צלצול חופשי** — מזינים דקות ושניות בנפרד, והערכים נשמרים כסך
  שניות. כל משך אפשרי (למשל 3 דקות ו-25 שניות = 205 שניות).
- **עקיפת הגדרות הצליל של הטלפון** (מתג לכל התראה):
  - ניגון בערוץ ההתראה (`STREAM_ALARM`) עם `USAGE_ALARM` — כך שמצב שקט
    ומצב רטט אינם משתיקים אותו.
  - הגברת עוצמת ערוץ ההתראה לעוצמה שנבחרה להתראה.
  - כיבוי זמני של מצב "נא לא להפריע" (דורש הרשאת גישה למדיניות
    ההתראות — האפליקציה מפנה להגדרות בפעם הראשונה).
  - רטט ללא תלות במצב הצלצול.
  - כל ערך שמשתנה מוחזר לקדמותו בסיום הצלצול.
- התראות מדויקות דרך `AlarmManager.setAlarmClock`, עם התראה במסך הראשי
  אם הרשאת ההתראות המדויקות חסרה.
- מסך צלצול מלא מעל מסך הנעילה, עם ספירה לאחור של הזמן שנותר,
  נודניק וכיבוי, וכן פעולות מקבילות בהתראה.
- שחזור כל ההתראות לאחר אתחול המכשיר או עדכון האפליקציה.

## הרשאות שכדאי לאשר

- **התראות** (Android 13+) — להצגת התראת הצלצול.
- **התראות מדויקות** (Android 12+) — כדי שההתראה תצלצל בזמן המדויק.
- **גישה למצב "נא לא להפריע"** — רק אם רוצים שההתראה תעקוף גם אותו.

## בנייה

```bash
cd AlarmClock
./gradlew assembleDebug
```

ה-APK ייווצר ב-`app/build/outputs/apk/debug/`. ה-workflow המשותף בריפו
בונה אותו אוטומטית ומעלה אותו כ-artifact בשם `AlarmClock-debug-apk`.
