# לוח שנה עברי (Hebrew Calendar)

אפליקציית לוח שנה עברי לאנדרואיד, מסונכרנת עם יומן Google, עם ווידג'ט חודשי
למסך הבית.

## מה יש באפליקציה
- **תצוגה חודשית עברית** (תשרי, חשוון... כולל אדר א׳/ב׳ בשנה מעוברת) עם
  התאריך הלועזי בקטן בכל משבצת. כפתור "תצוגה לועזית" מחליף לחודשים לועזיים עם
  התאריך העברי בקטן.
- **חגים ומועדים** (מנהג ארץ ישראל): ראש השנה, יום כיפור, סוכות, חנוכה, פורים,
  פסח, שבועות, צומות (כולל דחייה משבת), יום השואה/הזיכרון/העצמאות (לפי כללי
  ההקדמה והדחייה), ראשי חודשים ועוד. שבתות וימים טובים בצבע אדום.
- **סנכרון עם יומן Google**: האירועים מכל היומנים הגלויים במכשיר (כולל יומני
  Google) מוצגים בלוח, והתצוגה מתעדכנת מעצמה כשמגיעים שינויים מהסנכרון. כפתור
  "סנכרון" מבקש מהמערכת לסנכרן עכשיו.
- **הוספת אירוע ליומן Google** על היום שנבחר — של יום שלם או בשעה מסוימת, עם
  אפשרות **חזרה שנתית לפי התאריך העברי** (למשל יום הולדת עברי) לכמה שנים שבוחרים
  (עד 120) — דבר שיומן Google לא יודע לעשות בעצמו.
- **עיצוב אנדרואיד (Material 3)** עם **התאמה אישית**: צבעי הטפט או 5 ערכות צבע,
  בהיר/כהה/לפי המערכת, צורת סימון היום, הצגת תאריך לועזי, כותרות אירועים, חגים,
  קווי הפרדה וגודל טקסט. הווידג'ט מתעדכן בהתאם.
- **ווידג'ט חודשי** למסך הבית: לוח החודש עם החגים ונקודות לימים עם אירועים,
  חיצים למעבר בין חודשים, לחיצה על הכותרת חוזרת לחודש הנוכחי, ולחיצה על יום
  פותחת אותו באפליקציה. מתעדכן בחצות ובכל שינוי ביומן.

## איך הסנכרון עובד
האפליקציה לא מתחברת ישירות ל-Google API — היא קוראת וכותבת ליומן של מכשיר
האנדרואיד, ש-Google כבר מסנכרנת אוטומטית מול החשבון שלכם. לכן:
1. ודאו שחשבון Google מחובר במכשיר ושסנכרון "יומן" פעיל
   (הגדרות ← חשבונות ← Google ← סנכרון חשבון).
2. בפתיחה הראשונה אשרו לאפליקציה גישה ליומן.

אירוע שמוסיפים באפליקציה עולה ליומן Google תוך דקות (או מיד אחרי "סנכרון"),
ואירוע שמוסיפים ב-Google Calendar באתר מופיע באפליקציה ובווידג'ט אחרי הסנכרון.

## הוספת הווידג'ט
לחיצה ארוכה על מסך הבית ← ווידג'טים ← "לוח שנה עברי" ← גררו למסך.

## הורדה לטלפון
קישור הורדה ישיר לגרסה האחרונה (נפתח גם בטלפון, בלי התחברות):
https://github.com/AviMiler/MyApps/releases/download/hebrew-calendar-latest/HebrewCalendar.apk

## בנייה
- Android Studio: פתחו את התיקייה `HebrewCalendar/` ← Build ← Build APK(s).
- או דרך ה-workflow המשותף בריפו, שבונה APK debug ומריץ את בדיקות היחידה.
- בדיקות יחידה: `./gradlew testDebugUnitTest`.

## הערות
- התאריך העברי מחושב לפי היום האזרחי (חצות עד חצות), לא מהשקיעה.
- החישוב העברי כתוב ידנית (ולא עם `android.icu.util.HebrewCalendar`) כי ל-ICU
  יש באג בראש השנה תת״ז (2046) — ראו `ARCHITECTURE.md`.
