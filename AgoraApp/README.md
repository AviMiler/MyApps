# אפליקציית אגורה - דפדפן נעול לאתר יחיד

## מה זה עושה
- טוען אך ורק את agora.co.il / www.agora.co.il בתוך WebView.
- כל ניסיון ניווט (קישור, הפניה, פופאפ) לכתובת אחרת **נחסם** ולא נטען בתוך האפליקציה בשום מקרה — הוא מועבר החוצה למערכת (לדפדפן/אפליקציה שהיו אמורים לטפל בו).
- אם האפליקציה נפתחת דרך קישור שהוא לא agora.co.il, היא לא מציגה כלום — היא מעבירה מיד את הקישור החוצה וסוגרת את עצמה.

## איך בונים APK
1. פתח את התיקייה הזו ב-Android Studio (Open an existing project).
2. תן ל-Gradle להסתנכרן (יוריד תלויות אוטומטית).
3. Build > Build Bundle(s)/APK(s) > Build APK(s).
4. ה-APK יהיה תחת `app/build/outputs/apk/debug/app-debug.apk`.

## חשוב: מגבלת App Links
כדי שקישורים ל-agora.co.il ייפתחו אוטומטית באפליקציה (במקום בדפדפן), אנדרואיד דורש קובץ אימות בשם `assetlinks.json` שמתארח בכתובת:
```
https://agora.co.il/.well-known/assetlinks.json
```
מכיוון שזה לא האתר שלך, אין לך גישה להעלות את הקובץ הזה, ולכן אנדרואיד **לא** יאמת אוטומטית את הקישור (autoVerify).

**מה כן אפשר לעשות בלי שיתוף פעולה מבעל האתר:**
המשתמש יכול להגדיר את האפליקציה ידנית כברירת מחדל לפתיחת קישורים:
הגדרות מכשיר > אפליקציות > אגורה > פתיחה כברירת מחדל > הוסף קישור (Open by default).
במצב הזה, קישורי agora.co.il ייפתחו באפליקציה, וכל שאר הקישורים (שאינם agora.co.il) יועברו אוטומטית החוצה על ידי הקוד באפליקציה (ראה `MainActivity.kt`), כך שאין פגיעה בפתיחת קישורים לאפליקציות אחרות במכשיר.
