# הלאה — העברת SMS חכמה

אפליקציית אנדרואיד שמעבירה אוטומטית הודעות SMS מאנשי קשר (או שולחים) שבחרתם — לאיש קשר אחר
לבחירתכם. הכל קורה בתוך הטלפון: בלי שרתים, בלי חשבון ובלי מעקב.

האפליקציה בנויה סביב **מסלולים**: כל מסלול מחבר שולחים ← נמענים, עם צבע משלו כמו קו במפת
תחבורה. במסך הראשי כל מסלול מוצג כ"קו" שההודעות זורמות עליו מהשולחים אל הנמענים.

## פיצ'רים

### הבסיס
- **כמה מסלולים שרוצים** — לכל מסלול שולחים, נמענים, סינון, זמנים ופורמט משלו.
- **בחירת שולחים** מאנשי הקשר, מ**שולחים אחרונים** בתיבת ההודעות (נוח לבנקים ושירותים ששולחים
  בשם, כמו `Leumi` או `HOT`), או בהקלדה ידנית. אפשר גם "כל המספרים שלא שמורים" או "כולם", עם
  רשימת חריגים.
- **נמען אחד או כמה**, כולל מספרים שלא שמורים.
- זיהוי מספרים בכל פורמט (`+972`, `00972`, `050-...`) ושולחים בשם בלי תלות באותיות גדולות/קטנות.
- הודעות ארוכות (כמה חלקים) מאוחדות ומועברות כהודעה אחת.
- **אישורי שליחה ומסירה**, ו**ניסיונות חוזרים** אוטומטיים כשאין קליטה (עד 3 פעמים).
- **שני כרטיסי SIM**: בחירה דרך איזה כרטיס לשלוח (למסלול או כברירת מחדל), וסינון לפי הכרטיס
  שבו ההודעה התקבלה.
- **תבניות הודעה** עם שדות (`{sender}`, `{message}`, `{code}`, `{time}`, `{date}`, …), תבניות מוכנות,
  ותצוגה מקדימה חיה כולל **מונה עלות** — כמה הודעות SMS כל העברה תעלה (עברית = 70 תווים להודעה).

### סינון ותזמון
- מילות מפתח: "רק הודעות שמכילות…" / "לא הודעות שמכילות…".
- **קודי אימות בלבד (OTP)** — זיהוי חכם של קוד חד־פעמי בעברית ובאנגלית (מתעלם מסכומים, תאריכים,
  ספרות כרטיס ומספרי טלפון).
- **ימים ושעות** לכל מסלול (למשל רק א׳–ה׳ 08:00–18:00).

### פיצ'רים חדשים
- 📥 **קליטה מההתראות** — גיבוי למקרה שהטלפון לא מסר להלאה הודעת SMS: אם הגיעה התראה של אפליקציית
  ההודעות על הודעה שלא נקלטה כרגיל תוך כמה שניות, הלאה קולטת אותה מההתראה ומעבירה. הודעה שכבר
  נקלטה כרגיל לא מועברת פעמיים, והודעות קודמות שמופיעות שוב בהתראה מזוהות. כך נתפסות גם הודעות צ׳אט
  (RCS). ביומן מסומן אילו הודעות נקלטו מההתראה.
- 🔑 **קוד קודם** — תבנית שמציבה את הקוד בשורה הראשונה, כך שהנמען רואה אותו כבר בהתראה. הקוד
  מוצג גם ביומן ומועתק בנגיעה.
- 🕯️ **מצב שבת וחג** — הודעות שמתקבלות מהדלקת נרות ועד צאת השבת/החג נשמרות, ונשלחות אוטומטית
  כשהם יוצאים. זמני השקיעה מחושבים לפי עיר (18 ערים), עם דקות הדלקה/יציאה לבחירה (כולל 72 דק׳),
  וימים טובים לפי לוח ארץ ישראל. שבת וחג צמודים מתאחדים לחלון אחד.
- 🌙 **שעות שקט** — הודעות בשעות הלילה ממתינות לבוקר (או לא מועברות — לבחירתכם).
- 📬 **איחוד הודעות ממתינות** — כשכמה הודעות חיכו לאותו נמען, הן יוצאות כהודעה אחת מסודרת.
- ↩️ **תשובה חוזרת** — הנמען עונה עם `#` בתחילת ההודעה, והתשובה נשלחת לשולח המקורי (מאותו
  כרטיס SIM שבו ההודעה התקבלה).
- ⏳ **חלון ביטול** — 10 שניות עד 5 דקות עם התראה, ספירה לאחור וכפתור "ביטול" / "שלח עכשיו".
- ⏸️ **השהיה מהירה** — לשעה, עד הבוקר או עד שתמשיכו; בזמן השהיה ההודעות נשמרות (או לא — לבחירתכם).
  זמין גם כ**אריח בלוח ההגדרות המהירות** (Quick Settings) וכ**קיצור דרך** בלחיצה ארוכה על האייקון
  (יחד עם "מסלול חדש" ו"יומן").
- 🛡️ **הגנות** — מכסה יומית, מניעת כפילויות (הודעה שהגיעה פעמיים), עצירת מסלול שמוצף בהודעות
  (לולאה בין שני טלפונים), ומניעת העברה של הודעה אל השולח עצמו.
- 🧪 **בדיקת מסלול** — הקלידו הודעה לדוגמה וראו אם היא עוברת את הסינון ואיך תיראה, או שלחו בדיקה
  אמיתית לנמענים.
- 🩺 **בדיקת תקינות** — הרשאות, חיסכון בסוללה, שחרור מדויק בזמן, SIM ומצב טיסה, עם טיפים לפי יצרן
  הטלפון (Xiaomi, Samsung, Huawei, Oppo…).
- 📒 **יומן** — כל הודעה עם הסטטוס שלה (נשלח / נמסר / ממתין / נכשל / לא הועבר — ולמה), חיפוש,
  סינון, "שלח עכשיו", "נסה שוב" ו"להעביר בכל זאת". אפשר להסתיר את תוכן ההודעות ולקבוע כמה זמן
  לשמור את היומן.
- 💾 **גיבוי ושחזור** של המסלולים וההגדרות לקובץ JSON.
- 🎨 **עיצוב "מפת קווים"** — עברית מלאה מימין לשמאל, מצב כהה, גופני Rubik ו-Secular One, אנימציות
  של הודעות שזורמות על הקווים (נעצרות אם כיביתם אנימציות בהגדרות הנגישות), ומסך פתיחה שמסביר הכל.

## הרשאות

| הרשאה | חובה? | למה |
| --- | --- | --- |
| קבלה ושליחה של SMS | חובה | לראות הודעות נכנסות ולשלוח את ההעתק |
| אנשי קשר | מומלץ | בחירה מהרשימה והצגת שמות במקום מספרים |
| התראות | מומלץ | חלון ביטול, התראות על תקלות |
| החרגה מחיסכון בסוללה | מומלץ | שהמערכת לא תשהה את האפליקציה ברקע |
| קריאת הודעות | רשות | בחירת שולחים מתוך ההודעות האחרונות |
| גישה להתראות | מומלץ | קליטת הודעות שהטלפון לא מסר להלאה, והודעות צ׳אט (RCS) |
| מצב הטלפון | רשות | רק לטלפון עם שני כרטיסי SIM |
| התראות ותזכורות מדויקות | רשות | שחרור הודעות ממתינות בדיוק בזמן (למשל במוצאי שבת) |

## חשוב לדעת
- **אנדרואיד בלבד** — iOS לא מאפשר לאפליקציות לקרוא הודעות SMS.
- **הודעות צ'אט (RCS)** ו-**MMS** אינן SMS רגיל. הטקסט שלהן מועבר רק כשהקליטה מההתראות פעילה
  (תמונות לא מועברות).
- **אנדרואיד 13 ומעלה:** אפליקציה שהותקנה מקובץ APK עלולה להיחסם מהרשאות SMS ("הגדרות מוגבלות").
  אם בקשת ההרשאה לא מופיעה: הגדרות ← אפליקציות ← הלאה ← ⋮ ← "אפשר הגדרות מוגבלות", ואז לאשר שוב.
- Google Play Protect עשוי להציג אזהרה בהתקנה של אפליקציה שמטפלת ב-SMS — אפשר לבחור "התקנה בכל זאת".
- אנדרואיד מבקש אישור אם אפליקציה שולחת יותר מ-30 הודעות בחצי שעה.
- כל העברה היא הודעת SMS רגילה מהטלפון שלכם, בתעריף של הספק.

## מבנה הקוד
```
app/src/main/java/com/myappstore/smsforwarder/
├── core/        לוגיקה טהורה (Kotlin בלבד, עם בדיקות): התאמת מספרים, זיהוי קודים, תבניות,
│                מונה SMS, חלונות זמן, זמני שקיעה, לוח שבת/חג ומדיניות ההמתנה
├── data/        Room (מסלולים ויומן), הגדרות, גיבוי
├── sms/         קבלת SMS, שליחה עם אישורי שליחה/מסירה, כרטיסי SIM
├── engine/      מנוע ההעברה, תזמון (AlarmManager), התראות, אריח Quick Settings, ימים טובים
├── contacts/    אנשי קשר, שולחים אחרונים ותמונות
└── ui/          Jetpack Compose: מסך ראשי, עורך מסלול, בוחר אנשי קשר, יומן, הגדרות,
                 בדיקת תקינות ומסך פתיחה
```

## בנייה
1. פתחו את התיקייה `SmsForwarder` ב-Android Studio (Open an existing project) ותנו ל-Gradle להסתנכרן.
2. Build > Build Bundle(s)/APK(s) > Build APK(s).
3. ה-APK יהיה תחת `app/build/outputs/apk/debug/app-debug.apk`.

או דרך ה-workflow המשותף בריפו (`.github/workflows/build-apk.yml`), שבונה APK debug ומעלה אותו
כ-artifact בשם `SmsForwarder-debug-apk`. הרצה ידנית שלו (Actions ← Build APKs ← Run workflow)
גם מפרסמת את הקובץ ב-release בשם `smsforwarder-latest`, עם קישור ישיר להתקנה מהטלפון:
https://github.com/AviMiler/MyApps/releases/download/smsforwarder-latest/Halaa.apk

כל בנייה ב-CI חתומה במפתח debug חדש, ולכן כדי להתקין גרסה חדשה יותר צריך קודם להסיר את הקודמת
(כדאי לייצא גיבוי מההגדרות לפני כן ולשחזר אחרי ההתקנה).

בדיקות: `./gradlew testDebugUnitTest` מריץ את בדיקות הלוגיקה (התאמת מספרים, זיהוי קודים, תבניות,
זמני שקיעה, לוח שבת וחג, מדיניות ההמתנה, ניסוח בעברית), בדיקות של מנוע ההעברה מול מסד נתונים
בזיכרון, ובנוסף מצייר את כל המסכים עם נתוני דוגמה (Robolectric) לתיקייה `app/build/screenshots`.
